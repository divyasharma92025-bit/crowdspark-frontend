# 🧠 CrowdSpark Frontend

**CrowdSpark** is a modern MERN-based crowdfunding platform. This repository contains the frontend, built with React, Redux Toolkit, and Tailwind CSS.

It includes role-based dashboards, campaign discovery, real-time notifications, and Razorpay payment integration.

For the backend, visit the [CrowdSpark Backend Repository](https://github.com/divyasharma92025-bit/crowdspark-backend).

---

## 🌟 Project Overview

CrowdSpark provides a seamless user experience for crowdfunding, enabling users to discover campaigns, manage fundraising activities, make contributions, and receive real-time notifications.

## 🛠 Technology Stack

- **React + Vite** – Frontend framework and build tool
- **Tailwind CSS** – Responsive styling
- **Redux Toolkit** – State management
- **Axios** – API communication
- **Socket.IO Client** – Real-time notifications
- **Razorpay** – Payment integration

## ✨ Key Features

- Role-based dashboards for Admin, Campaign Owner, and Backer
- User authentication using HttpOnly cookies
- Campaign creation, editing, and discovery
- Razorpay payment integration
- Invoice downloads
- Role upgrade request system
- Real-time notifications
- Admin dashboard for user and campaign management

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/divyasharma92025-bit/crowdspark-frontend.git
cd crowdspark-frontend
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

Create a `.env` file if required by your project and configure the backend API URL according to your application's setup.

**Important:** Never commit API secrets, passwords, or private environment variables.

### 4. Run the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal.
